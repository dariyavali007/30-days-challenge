# 30 Day Challenge Tracker

A simple 30-day habit tracker built with HTML, CSS, and JavaScript, featuring daily progress, streaks, and separate challenge calendars.

## Challenges

- 🏃 Exercise Daily
- 📖 Read Daily

## Features

- 30-day calendar
- Only today's day can be completed
- Future days are locked
- Previous days cannot be changed
- Cross-out X for completed days
- Current and best streaks
- Progress percentage and progress bar
- Separate progress for each challenge
- Browser localStorage
- Responsive design

## Files

- `index.html` — page structure
- `style.css` — design
- `script.js` — functionality

## Run locally

Open `index.html` in a browser.

## GitHub Pages

Upload all files to the root of your GitHub repository and enable GitHub Pages from:

**Settings → Pages → Deploy from a branch → main → / (root)**.
